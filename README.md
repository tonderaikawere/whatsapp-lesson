## 🚀 About The Project & Showcase

This project was built from the ground up to demonstrate what I can do as a Full-Stack Software Engineer — specifically designing and implementing:
1. **Pixel-Faithful UI/UX:** A comprehensive recreation of the WhatsApp Web interface with exact typography, color palettes, spacing, and interaction details.
2. **Dynamic AI Chatbot:** Context-aware interactive assistant providing instant responses, coding jokes, tech stack overviews, and portfolio guidance.
3. **Full Responsiveness:** Seamless adaptive layouts across mobile smartphones, tablets, laptops, and ultra-wide desktop monitors with back navigation.
4. **Theme Customization:** Complete dark mode and light mode switching conforming to WhatsApp Web design standards.
5. **Zero-Dependency Web Audio:** Real-time synthesized message send and receive audio tones generated natively through the Web Audio API without requiring external MP3 downloads.
6. **Simulated Media & Voice Notes:** Dynamic voice note player bubbles, emoji picker, attachment action menus, and simulated call dialogs.

## 🛠️ Tech Stack & Architecture

- **Framework:** [Next.js](https://nextjs.org/) (App Router, Turbopack, TypeScript)
- **UI Component System:** [Material UI (MUI v6)](https://mui.com/)
- **Styling Engine:** Emotion CSS-in-JS + Material Design tokens
- **Audio Synthesizer:** Native HTML5 Web Audio API
- **Icons:** Material Icons & SVG Badges
- **Deployment:** Vercel / Node.js production container

## 💻 Getting Started

### Prerequisites
- Node.js v18 or higher (v24 recommended)
- npm or yarn

### Installation
```bash
# 1. Clone the educational repository
git clone https://github.com/tonderaikawere/whatsapp-lesson.git

# 2. Navigate to project directory
cd whatsapp-lesson

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to experience the application.

### Production Build
```bash
npm run build
npm run start
```
